# PFR KPI — Система расчёта ключевых показателей эффективности

**Автоматизированная система KPI** для подразделений и сотрудников (адаптировано под ПФР / Социальный фонд России или аналогичные структуры).

Полноценное **full-stack** приложение:
- **Backend** — API для расчётов, хранения данных и авторизации
- **Frontend** — современный интерфейс с дашбордами и отчётами

---

## ✨ Основные возможности

- Автоматический расчёт KPI по формулам и весам
- Периоды: месяц / квартал / год / произвольный
- Иерархия сотрудников и подразделений
- Роли: Администратор / Руководитель / Сотрудник
- Интерактивные графики и дашборды
- Экспорт в Excel и PDF
- Фильтры, поиск, сортировка
- Адаптивный дизайн

## 🚀 Быстрый старт

## Запуск 

Переходим в директорию (frontend и backend) и запускаем npm run dev:
